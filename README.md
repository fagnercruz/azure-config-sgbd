# Criando instância de Banco de Dados no Azure
repo com documentação para a criação de uma instância de banco de dados no Azure

## Configuração

Acessar o painel > Criar novo recurso

![01](https://github.com/user-attachments/assets/ac5ee522-f0e5-4a4e-b604-a3857acb5f57)

Acessar Banco de Dados > SQL Database
![02](https://github.com/user-attachments/assets/1efffe68-1c3a-4f92-950c-9649fe2dedfd)

Em Detalhes do banco de dados, preencha os dados e em Servidor, clique no link "Criar novo"
![03 0](https://github.com/user-attachments/assets/7fd058a4-4284-4330-b8b2-5e0ea93a23c5)

Na tela de "Criar Servidor do Banco de Dados SQL", preencha os dados solicitados
![03 1](https://github.com/user-attachments/assets/bc1bef5f-e9b4-4856-8a25-ed3dd8444876)

Em Redundância do armazenamento de backup, selecione a opção que melhor se enquadra nas suas necessidades
![04](https://github.com/user-attachments/assets/26b0c03f-07e0-4e5a-98ad-34e09051d213)

Analise os custos mensal do servidor e clique em "Revisar + criar" ou "Avançar" para personalizar mais opções
![05](https://github.com/user-attachments/assets/d761e71b-9b45-434b-af07-da35f9c45f59)
